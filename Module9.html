1.1 The Curse of Dimensionality: Why More Features Can Hurt

As the number of features increases, the feature space becomes exponentially sparse. Distance metrics become meaningless, and you need exponentially more data to maintain statistical significance.

📖 Core Insight: In high dimensions, all points become approximately equidistant — making nearest neighbor and distance-based methods fail.
📊 Volume Explosion
\[ \text{Volume} \propto r^d \]

With 10 dimensions, 90% of the volume lies in the outermost 10% of the range. Data becomes sparse.

📈 Sample Size Needed

To maintain the same density, sample size must grow exponentially with dimensions.

2.1 Principal Component Analysis (PCA) — Linear Reduction

PCA finds orthogonal axes (principal components) that maximize variance. Projects data onto top-k components, preserving the most important patterns.

\[ \text{PCA: } X' = XW_k \quad \text{where } W_k \text{ are top k eigenvectors of } X^TX \]
✅ Advantages
  • Fast, deterministic
  • Removes multicollinearity
  • Excellent for visualization (2D/3D)
  • No hyperparameters (except k)
⚠️ Limitations
  • Only linear relationships
  • Components are hard to interpret
  • Assumes high variance = important
  • Sensitive to scaling
💡 Always standardize features before PCA! Otherwise, features with large scales dominate.

2.2 Explained Variance & Choosing Components

The explained variance ratio tells how much information each component preserves. Look for the "elbow" in the cumulative variance curve.

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

pca = PCA(n_components=0.95)  # keep 95% variance
X_pca = pca.fit_transform(X_scaled)

print(f"Original dims: {X.shape[1]} → Reduced: {X_pca.shape[1]}")
print(f"Explained variance: {pca.explained_variance_ratio_.sum():.2%}")

3.1 t-SNE: Non-linear Visualization

t-Distributed Stochastic Neighbor Embedding (t-SNE) excels at preserving local structure, making it ideal for visualizing clusters in 2D/3D. However, it's stochastic and distances between clusters are not meaningful.

🎯 t-SNE is for visualization only — never use it as a preprocessing step for other models!
Key Parameters
  • perplexity (5-50): balances local/global structure
  • learning_rate: typical 200-1000
  • Output: 2D or 3D coordinates
⚠️ Pitfalls
  • Results change each run (random seed)
  • Can create false clusters
  • Slow for large datasets (>10k points)

3.2 UMAP: Uniform Manifold Approximation

UMAP is faster than t-SNE and better preserves global structure. It scales to millions of points and can produce embeddings usable for downstream tasks.

⚡ Speed Comparison (10k points, 50 dims): t-SNE ~ 2-3 min, UMAP ~ 10-15 sec. UMAP also supports supervised and semi-supervised reduction. 
import umap
reducer = umap.UMAP(n_components=2, random_state=42)
embedding = reducer.fit_transform(X_scaled)

# Supervised UMAP (uses labels)
reducer_sup = umap.UMAP(n_components=2, target_weight=0.5)
embedding_sup = reducer_sup.fit_transform(X_scaled, y)

4.2 Autoencoders: Deep Learning for Reduction

Autoencoders learn a nonlinear mapping to a low-dimensional bottleneck, then reconstruct the original input. The bottleneck activations serve as reduced features.

\[ \text{Encoder: } z = f(x) \quad \text{Decoder: } \hat{x} = g(z) \quad \text{Loss} = \|x - \hat{x}\|^2 \]
💡 Use autoencoders when PCA underperforms due to nonlinear relationships and you have enough data to train a neural network.

4.3 Dimensionality Reduction Workflow

🔧 Best Practice Pipeline:
  1. Standardize all numerical features
  2. Start with PCA (linear, fast baseline)
  3. Evaluate explained variance & downstream model performance
  4. If visualization needed → t-SNE/UMAP on PCA-reduced data
  5. For high-performance nonlinear reduction → UMAP or Autoencoder
  6. Always validate with cross-validation on the reduced space

5.1 Complete Dimensionality Reduction Pipeline

import numpy as np
import pandas as pd
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import umap
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import matplotlib.pyplot as plt

# Load data
digits = load_digits()
X, y = digits.data, digits.target
print(f"Original shape: {X.shape}")  # 1797 x 64

# Standardize
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA: keep 95% variance
pca = PCA(n_components=0.95)
X_pca = pca.fit_transform(X_scaled)
print(f"PCA reduced: {X_pca.shape[1]} components, var={pca.explained_variance_ratio_.sum():.2%}")

# UMAP for 2D visualization
reducer = umap.UMAP(n_components=2, random_state=42)
X_umap = reducer.fit_transform(X_scaled)

# Visualize
plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='Spectral', s=5)
plt.title("UMAP projection of digits")
plt.colorbar()
plt.show()

# Compare classifier accuracy on original vs PCA-reduced
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, random_state=42)
clf_orig = RandomForestClassifier(n_estimators=50).fit(X_train, y_train)
acc_orig = clf_orig.score(X_test, y_test)

X_train_pca, X_test_pca = train_test_split(X_pca, test_size=0.2, random_state=42)
clf_pca = RandomForestClassifier(n_estimators=50).fit(X_train_pca, y_train)
acc_pca = clf_pca.score(X_test_pca, y_test)

print(f"Original acc: {acc_orig:.3f} | PCA acc: {acc_pca:.3f}")

5.2 Explained Variance Plot (Elbow Method)

import matplotlib.pyplot as plt
from sklearn.decomposition import PCA

pca_full = PCA()
pca_full.fit(X_scaled)

cumsum = np.cumsum(pca_full.explained_variance_ratio_)
plt.plot(range(1, len(cumsum)+1), cumsum, 'bo-')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% variance')
plt.xlabel('Number of components')
plt.ylabel('Cumulative explained variance')
plt.title('PCA: Choose components at elbow')
plt.legend()
plt.grid(True)
plt.show()

# Optimal k where cumulative variance reaches 95%
k_95 = np.argmax(cumsum >= 0.95) + 1
print(f"Optimal components for 95% variance: {k_95}")

6.2 Module Summary

📚 Key Takeaways:
  • Curse of dimensionality: sparse data, distances break down
  • PCA: linear, fast, preserves global variance — standard preprocessing
  • t-SNE: excellent for cluster visualization, stochastic, not for downstream tasks
  • UMAP: faster than t-SNE, preserves local+global structure, scalable
  • Autoencoders: nonlinear deep reduction for large datasets
  • Always standardize before PCA/t-SNE/UMAP
\[ \text{Choose reduction method} = \begin{cases} \text{PCA} & \text{linear, speed, preprocessing} \\ \text{t-SNE} & \text{visualization only} \\ \text{UMAP} & \text{visualization + scalable} \\ \text{Autoencoder} & \text{nonlinear & abundant data} \end{cases} \]
