📖 Introduction: Neural Networks = Logistic Regression, but More Powerful

Logistic regression is one of the most fundamental classification algorithms. It takes a linear combination of inputs, passes it through a sigmoid function, and outputs a probability:

\[ \hat{y} = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b) = \frac{1}{1 + e^{-(w_1 x_1 + \dots + b)}} \]

Sigmoid function: maps any real number \(z\) to a probability between 0 and 1.

A single neuron is exactly a logistic regression unit!

  • Weights \(w_i\) → coefficients
  • Bias \(b\) → intercept
  • Sigmoid activation → probability output

🧠 Key insight: If you understand logistic regression, you already understand a single neuron. A neural network simply stacks many such units (neurons) in layers, allowing it to learn much more complex, non‑linear patterns.

💡 Bottom line: A neural network is not magic – it is a natural extension of logistic regression. By adding hidden layers and non‑linear activations, we give the model the ability to learn features automatically and solve much harder problems. The core mathematics (weighted sum + activation + gradient descent) remains the same.

Neural networks are powerful but not always the right tool. This decision guide helps you choose.

🎯 Specific Scenarios: When to Reach for Neural Networks

✅ Good candidates

  • Image classification / object detection
  • Speech recognition, audio processing
  • Natural language processing (translation, sentiment, chatbots)
  • Time series forecasting with long dependencies (LSTM, Transformers)
  • Recommender systems (collaborative filtering with embeddings)
  • Games and reinforcement learning
  • When you have >100k labeled examples

❌ Avoid (or try simpler models first)

  • Small datasets (< 1,000 samples) → overfitting risk
  • Tabular data with well‑engineered features → XGBoost often beats NNs
  • Need for high interpretability (medical, finance, legal)
  • Limited computational resources (no GPU, edge devices with low power)
  • Linear or nearly linear relationships → logistic/linear regression is enough
  • When you need a quick baseline or fast iteration

🧬 Inside a Neuron: Logistic Regression Unit

A single neuron computes: \( z = \sum w_i x_i + b \) then applies an activation \( f(z) \).

  • Weights (\(w\)) = coefficients in logistic regression
  • Bias (\(b\)) = intercept term
  • If activation is sigmoid → exactly logistic regression!

⚡ Activation Functions: From Logistic to Deep Learning

Different activations serve different purposes. The table below shows the most important ones.

🔹 Sigmoid (Logistic)

Formula: \( \sigma(z) = \frac{1}{1+e^{-z}} \)
Range: (0,1)
Use: Binary output layer.

Example: \( z=2.0 \) → \( \sigma \approx 0.8808 \)

🔹 Tanh

Formula: \( \tanh(z) = \frac{e^{z}-e^{-z}}{e^{z}+e^{-z}} \)
Range: (-1,1)
Use: Hidden layers (zero-centered).

Example: \( z=1.0 \) → \( \tanh \approx 0.7616 \)

🔹 ReLU

Formula: \( \max(0,z) \)
Range: [0,∞)
Use: Default for hidden layers.

Example: \( z=-0.5 \) → 0 ; \( z=3.2 \) → 3.2

🔹 Softmax (Multi‑class)

Formula: \( \frac{e^{z_i}}{\sum_j e^{z_j}} \)
Range: (0,1) sums to 1
Use: Multi‑class output.

Example: \( z=[2.0,1.0,0.1] \) → probs ≈ [0.659, 0.242, 0.099]

🔁 How It Learns (Backpropagation)

  1. Forward pass – compute prediction \(\hat{y}\).
  2. Loss calculation – binary cross‑entropy \( \mathcal{L} = -[y\log\hat{y} + (1-y)\log(1-\hat{y})] \).
  3. Backward pass – compute gradients of loss w.r.t every weight.
  4. Update – \( w \leftarrow w - \eta \frac{\partial \mathcal{L}}{\partial w} \) (gradient descent).

🚀 Deep Learning: Scaling Up

A deep neural network is simply a neural network with many hidden layers (typically > 2). Deep learning has revolutionised AI by automatically learning hierarchical features.
